# Prakash A Portfolio Website

A modern portfolio website built to showcase the skills, projects, education, experience, and contact details of Prakash A.

## Live Demo

https://prakashalagundagi.github.io/My-Website-/

## Overview

This project is a personal portfolio website designed for a Computer Science student and aspiring software developer. It includes a polished hero section, project showcase, skills summary, experience details, and contact options.

## Key Features

- Responsive hero section with animated particle background
- Profile presentation with tilt animation effects
- Skills and achievements highlights
- Project showcase with interactive cards
- About section with education and career goals
- Experience section with timeline-style layout
- Contact links and EmailJS integration for messaging
- Mobile-friendly menu and smooth scrolling navigation

## Built With

- HTML5
- CSS3
- JavaScript
- Font Awesome
- particles.js
- Vanilla Tilt
- EmailJS

## Repository Structure

- `index.html` — main portfolio page
- `experience/index.html` — experience section page
- `projects/index.html` — projects showcase page
- `assets/css/style.css` — styling and responsive layout
- `assets/js/app.js` — particles.js configuration
- `assets/js/script.js` — interaction handling and contact behavior
- `assets/js/particles.min.js` — particle animation library
- `assets/images/hero.jpg` — hero profile image

## Getting Started

To view this portfolio locally:

```bash
git clone https://github.com/prakashalagundagi/My-Website-.git
cd My-Website-
```

Open `index.html` in your browser, or use a local development server for best results.

## Deployment

This repository is ready for deployment on GitHub Pages or any static site hosting service.
